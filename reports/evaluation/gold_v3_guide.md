## ชุดนี้คืออะไร

ชุด gold เดิม 300 ใบสุ่มมาแบบไม่แบ่งชั้น จึงเป็นร้านอาหารเกือบทั้งชุด
ทำให้หมวดของสถานที่ท่องเที่ยว วัด ตลาด มีตัวอย่างไม่พอวัดผล
ชุดนี้บังคับโควตาตามประเภทสถานที่ เพื่อให้ทุกหมวดวัดผลได้

⚠️ **ชุดนี้ไม่เป็นตัวแทนประชากร** สัดส่วนประเภทสถานที่ถูกบิดโดยเจตนา
ห้ามเอาสัดส่วนในชุดนี้ไปอ้างเป็นสัดส่วนของจังหวัด

⚠️ ติดป้ายด้วย **ชุดหมวด v3.1 (13 หมวด)** ไม่ใช่ v2 ที่ระบบใช้อยู่

## วิธีกรอก

| ช่อง | กรอกอะไร |
|---|---|
| `overall_sentiment` | `positive` · `neutral` · `negative` |
| `aspects` | `<เลขหมวด><เครื่องหมาย>` คั่นจุลภาค · `+` ชม `n` กลางๆ `-` ติ · เช่น `1+,3-` |
| `no_specific_topic` | ใส่ `1` ถ้าชมหรือติแบบไม่บอกว่าเรื่องอะไร แล้ว `aspects` ต้องว่าง |

⚠️ ห้ามใส่หมวดเดียวกันสองครั้งในรีวิวเดียว

⚠️ ข้อความที่อ่านไม่เข้าใจ ให้เว้น `overall_sentiment` ว่างไว้
แถวนั้นจะถูกตัดออกจากการคิดคะแนน ไม่นับว่าผิด

ไม่แน่ใจจริง ๆ ให้เว้นว่าง ดีกว่าเดา

## กติกาที่ต้องใช้

### การสักการะมีหมวดของตัวเองแล้ว (เลิกยัดเข้าหมวดไม่ระบุประเด็น)

**รีวิวที่พูดถึง กราบ / สักการะ / ไหว้พระ / ขอพร / ทำบุญ / อิ่มบุญ / นมัสการ / แก้บน / ใส่บาตร / ทอดกฐิน / สวดมนต์ / ทำสมาธิ / พิธีกรรม / ศักดิ์สิทธิ์ / ขลัง / ศรัทธา หรือกล่าวถึงพระพุทธรูปหรือพระสงฆ์ที่เคารพ (ประดิษฐาน... หลวงพ่อ...) = หมวด 10**

ที่มา:
- กติกา v2 เกิดจากคู่มือเดิมขัดกันเอง แล้วเลือกยึดตามชุด gold
- แต่ 'มากราบสักการะ' ระบุประเด็นชัดเจน คือกิจกรรมที่ทำที่นั่น
- การยัดเข้าหมวด 2 (v2) ที่ชื่อว่า 'ไม่ระบุประเด็น' ผิดตามความหมายของคำ
- ผู้ใช้ติดป้ายเอง 79 รายการ เจอเคสสักการะ 3 ครั้ง ขัดกติกา v2 ทั้ง 3 ครั้ง
- วัดได้ว่าหมวด 2 (v2) เป็นหมวดอันดับหนึ่งของวัด (31%) ซึ่งเป็นอาการของปัญหา

### ไม่ระบุประเด็น เป็นธงบนรีวิว ไม่ใช่หมวด

**รีวิวที่ชมหรือติแบบไม่บอกว่าเรื่องอะไร (เช่น 'ดีมาก', 'ไม่ชอบ') ให้ติดธง no_specific_topic บนตัวรีวิว และไม่ต้องมีแถวหมวดเลย**

ที่มา:
- ผู้ใช้ติดป้ายเอง 79 รายการ ไม่เลือกหมวด 2 (v2) เลยสักครั้ง (gold เลือก 4)
- คนหาหมวดที่เจาะจงได้ทุกครั้ง หมวดนี้จึงไม่ใช่หมวดตามธรรมชาติ
- การมีหมวดที่หมายถึง 'ไม่มีหมวด' ทำให้สถิติรายหมวดอ่านไม่ได้

### รีวิวที่มีทั้งชมและติ ให้ชั่งน้ำหนัก ไม่ใช่ตัดสินจากการมีคำติ

1. 1. มีแต่ติ ไม่มีชม -> negative
2. 2. มีแต่ชม ไม่มีติ -> positive
3. 3. มีทั้งชมและติ ให้ชั่งน้ำหนัก
   ติเป็นหลัก -> negative
   ชมเป็นหลัก และคำติเบาหรือพูดผ่าน ๆ (เช่น ไปหน่อย ไปนิด นิดนึง) -> positive
   น้ำหนักพอกัน -> neutral
7. 4. ไม่มีทั้งชมและติ -> neutral

ที่มา:
- กฎเดิมข้อ 1 เขียนว่า 'มีการติ ไม่ว่าสุภาพแค่ไหน = negative'
- อ่านตามตัวอักษรแล้วนิยามของ positive ('ชมเป็นหลัก มีติเล็กน้อย') และ
- ของ neutral ('ชมกับติพอกัน') จะไม่มีทางเกิดขึ้นได้เลย = คู่มือขัดกันเอง
- วัดจาก gold: รีวิวที่มีทั้งหมวดชมและหมวดติ 23 ใบ -> neutral 14 (61%)
- positive 7 (30%) negative 2 (9%) คือ gold ชั่งน้ำหนักอยู่แล้วในทางปฏิบัติ
- ขั้นชั่งน้ำหนักหายไปจากรายการกฎ มีอยู่แต่ในบรรทัดเข้าข่ายของแต่ละป้าย

### metadata ของ Google ที่ปนในข้อความ ไม่ใช่คำของผู้รีวิว

**ข้อความรีวิวที่เก็บมามี metadata ของ Google ปนอยู่ ห้ามใช้ส่วนนั้น เป็นหลักฐานว่าผู้รีวิวพูดถึงอะไร ให้อ่านข้ามไป**

| รูปแบบ metadata | จำนวนรีวิว |
|---|---|
| ช่วงราคาท้ายข้อความ เช่น ฿200-300 | 1,731 |
| timestamp ของวิดีโอ เช่น 0:08 0:12 | 624 |
| คำนำหน้าวันที่ เช่น '2 วันที่ผ่านมา' '5 ชั่วโมงที่ผ่านมา' | 473 |
| ท้ายข้อความ 'วันธรรมดา' | 382 |
| ท้ายข้อความ 'วันหยุด' / 'วันหยุดนักขัตฤกษ์' | 73 |
| ขึ้นต้นด้วยวันที่เต็ม เช่น '7 มกราคม 2023' | 12 |
| ท้ายข้อความ 'สุดสัปดาห์' | 0 |

รูปแบบที่ต้องอ่านข้ามทั้งหมด

- ช่วงราคา ฿1-200 / ฿1 / ฿... ที่ถูกตัดท้าย
- ช่องประเมินราคา 'การประเมินราคา ...' เช่น 'การประเมินราคา ราคาสุดคุ้ม'
- วันที่เข้าชม วันธรรมดา / วันเสาร์-อาทิตย์ / วันหยุดนักขัตฤกษ์ และรูปที่ถูกตัดท้าย เช่น 'วันธรร' 'วันเส'
- ประเภทการใช้บริการ 'รับประทานที่ร้าน' และรูปที่ถูกตัด 'รับประทานที่ร'
- วันที่นำหน้า ทั้งแบบสัมพัทธ์ '6 วันที่ผ่านมา' และแบบเต็ม '7 มกราคม 2023'
- ความยาววิดีโอ '0:08 0:06'
- คะแนนย่อยที่ถูกตัดท้าย เช่น 'อาหา...'

### กติกา A — หมวดเดียวมีทั้งชมและติ

1. ถ้าหมวดเดียวได้ทั้งคำชมและคำติ (เช่น 'อร่อยแต่ได้น้อย' ซึ่งทั้งสองเรื่องอยู่หมวด 1) ให้ชั่งน้ำหนักภายในหมวดนั้นเอง
2. ด้านใดด้านหนึ่งเด่นชัด -> ใช้เครื่องหมายของด้านนั้น
3. น้ำหนักพอกัน -> n
